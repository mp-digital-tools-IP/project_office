# МП Проекты — функциональная модель v0.1

## Пилот СЦ-2
Портфель → проект → контрольная точка → задача → подзадача. Фаза (инициация, планирование, реализация, завершение) — независимое поле проекта, не дополнительный обязательный контейнер.

## Независимые классификации
- Цикл проекта: Новый / Продолжающийся / Перезапускающийся.
- Согласование инициативы: Черновик / На рассмотрении / Предложение / Предварительно одобрено / Утверждение / Инициация; Отложен / Отклонён.
- Здоровье проекта: зелёный / жёлтый / красный — автоматический расчёт, РП пишет комментарий.
- Рабочий статус задачи: К выполнению / В работе / На проверке / Выполнена / Заблокирована.
- Сроковое состояние задачи: в срок / скоро срок / просрочена / завершена вовремя / раньше / поздно.

## Контрольные точки
Уровни КТ-0, КТ-1, КТ-2; срок, ответственный, результат, критерий, подтверждение; передача на приёмку; Принять / Вернуть на доработку с объяснением. В пилоте принимает руководитель портфеля.

## Статусы здоровья: рабочая гипотеза
Красный: КТ просрочена **более 14 дней**, критический риск, существенное финансовое превышение.
Жёлтый: КТ просрочена до 14 дней, наступает в ближайшие 7 дней, не обновлён месячный отчёт, умеренное превышение бюджета.
Иначе зелёный. Пороги для KPI, бюджета и критических рисков требуют последующего утверждения.

## Роли
Руководитель портфеля: обзор, отчёты, приёмка контрольных точек.
РП: создание/редактирование/закрытие любых задач своего проекта; месячный отчёт.
Участник: создание задач и ведение проектных обсуждений.
Проректор: портфельный обзор.
Ректор: отдельное обзорное представление.
ЦПО: наблюдатель.
Администратор: учётные записи и настройки.

## Управленческие экраны v1
Дашборд портфеля; реестр; паспорт; Kanban; календарь всех КТ; инициативы и маршрут; автоматические отчёты; лента событий; настройки.

## Финансы v1
Утверждено / законтрактовано / потрачено / остаток / отклонение.

## Ежемесячный отчёт
Структурированная форма: что сделано, план следующего месяца, риски и отклонения, комментарий к статусу, запрос на управленческое решение. Повторяющиеся показатели подставляются автоматически.

## Дальнейшие улучшения
